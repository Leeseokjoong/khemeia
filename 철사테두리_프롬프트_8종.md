# 철사 테두리 남은 8종 — 붙여넣기용 프롬프트

불철사(ignis)는 완료. 아래는 검증된 교정 프롬프트에서 **THEME 줄만** 교체한 것.
본문은 한 글자도 건드리지 말 것 — 밀도가 다시 올라간다.

생성 후: `python tools/wire_process.py --batch raw/ assets/`

---

## 공통 본문 (모든 프롬프트에 그대로 들어감)

```
A game UI panel border made of ONE single continuous thin wire line, for 9-slice scaling.
Square, symmetrical, on FLAT PURE BLACK. The wire is a SINGLE HAIRLINE STROKE of uniform
thickness that runs straight along each of the four edges — it does NOT fill a band and does
NOT weave back and forth. Sprouting off that line, spaced far apart, are only TWO OR THREE
small spiral curls per edge, each curling inward like a tendril. At each corner the wire loops
once into a small knot. AT LEAST 90 PERCENT OF THE IMAGE MUST BE EMPTY BLACK — extremely
sparse, airy, minimal, lots of negative space. This is a delicate wrought-iron filigree line,
NOT a thick ornate frame, NOT dense scrollwork, NOT a decorative band.
THEME: <여기만 교체>
Crisp clean 2D game asset. NO text, NO watermark, NO solid frame.
```

## 주의

- **ferrum / lime 은 발광이 거의 없다.** 후처리가 밝기→알파라서, 너무 어두우면
  변환 후 선이 통째로 사라진다. 생성 시 프롬프트 끝에
  `brightly lit against the black background` 를 덧붙이거나,
  변환 시 FLOOR 를 낮춰서 (`tools/wire_process.py` 상단 `FLOOR = 12` → `6`) 살릴 것.
- 뽑고 나면 반드시 **슬라이스 실측값을 확인**한다. 스크립트가 변별로 찍어준다.
  불철사는 105 였다. 다른 종이 ±15 이상 벗어나면 그 종만 CSS를 따로 잡거나
  다시 뽑는 게 낫다 (`border-image` slice 는 --wire 하나로 공유됨).
