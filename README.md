# 케미아: 정화의 연금술 (KHEMEIA)

**화학 반응이 그대로 전투 규칙이 되는 턴제 카드 RPG**

> 물로 불을 끄고, 산으로 석회를 녹인다.
> 정답을 외워서 이기는 게임이 아니다. 물질이 어떻게 반응하는지 알아내야 이긴다.

**▶ [지금 바로 플레이](https://leeseokjoong.github.io/khemeia/)** · 설치 불필요, 브라우저에서 바로 실행

## 무엇이 다른가

화학을 다루는 게임은 대개 **퀴즈를 맞히면 캐릭터가 공격하는** 구조입니다. 퀴즈를 걷어내도 게임은 굴러갑니다. 붙여 놓은 것에 불과합니다.

케미아는 **반응식 자체가 전투 규칙**입니다. 퀴즈 창이 한 번도 뜨지 않습니다.

- 불의 지배자에게 이기려면 **H₂O를 만들어야** 한다 → 수소 2개와 산소 1개를 슬롯에 놓는 것 외에 방법이 없다
- 너무 뜨거우면 **물이 닿기 전에 증발**한다 → 먼저 식혀야 한다 (기화열)
- 기름 불에 물을 부으면 **불길이 퍼진다** → CO₂로 산소를 끊어야 한다 (유류 화재는 B급)
- 물을 쏘면 전장이 젖는다 → 젖은 곳에 **나트륨을 던지면 폭발**한다 (2Na + 2H₂O → 2NaOH + H₂↑)
- **물의 지배자에게 물을 부으면 오히려 회복**한다 — 생성물이 상대의 양분이면 통하지 않는다

### 계수비 — 이 게임이 진짜로 가르치는 것

콤보는 **계수비가 정확할 때만** 발동합니다. `2H₂ + O₂`를 3 : 1로 놓으면 터지지 않고 *"수소가 하나 남았다"*고 알려줍니다. 계수는 외우는 숫자가 아니라 **맞춰야 하는 손동작**이 됩니다.

반응식은 **스무 개뿐이고 늘릴 계획도 없습니다.** 목표는 개수가 아니라 *"계수를 맞추는 방법"* 하나를 몸에 남기는 것입니다.

## 플레이 방법

```
원소를 캔다 → 손패로 뽑는다 → 슬롯에 정확한 개수로 놓는다 → 분자가 된다
   → 발사 → 판의 상태(온도·pH·젖음·압력·산소)가 바뀐다 → 다음 반응이 달라진다
```

- **합성**: 손패의 원소 카드를 슬롯에 놓고 `합성!` — 원자 구성이 맞으면 분자가 됩니다
- **➕ 이음매**: 카드 사이의 작은 `＋`를 누르면 묶음이 갈라집니다. `H H ＋ H H ＋ O O` = `2H₂ + O₂` 반응식 콤보
- **지역 봉인**: 각 지역 보스는 **그 지역에서 배운 반응식으로만** 갈라지는 봉인을 두릅니다. 다른 콤보는 65% 흡수
- **막히면**: 계수 저울에서 12초 고민하면 정답 대신 **세는 방법**을 알려줍니다

## 기술 구성

- **단일 HTML 파일** · 외부 프레임워크·빌드 도구 의존 없음. `index.html`을 브라우저로 열면 그대로 실행됩니다
- **모든 에셋에 폴백** — 그림이 없으면 이모지·CSS로 대체되어 화면이 비지 않습니다
- **로직 검증 자동화** — 게임 코드의 실제 함수를 추출해 헤드리스로 돌려 *"몇 턴에 클리어되는가 / 잘못된 선택이 정말 실패하는가"* 를 수치로 확인한 뒤 배포합니다
- **화학 규칙 일관성 검사** — 지역의 화학 규칙이 보스뿐 아니라 그 지역 몬스터 전체에 똑같이 적용되는지, 각 지역의 봉인 반응식이 그 지역에서 실제로 조달 가능한지를 코드가 스스로 확인합니다

